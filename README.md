# Dartmouth Pong

Browser recreation of Dartmouth-style paddle pong. See [DESIGN.md](DESIGN.md) for the spec.

```sh
npm install
npm run dev     # play at http://localhost:5173
npm test        # unit tests (Vitest)
npm run build
```

Status: Phase 1, step 1 (table + cup formations) done. Step 2 test plan awaiting review: [docs/phase1-test-plan.md](docs/phase1-test-plan.md).
